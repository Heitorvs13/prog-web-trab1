# Declaração do Trabalho

Título do Projeto: Loja Virtual de Vinis


## 1. Objetivo
Estruturar e estilizar um conjunto de páginas web, utilizando os padrões HTML5 e CSS3

O foco será na aplicação de elementos semânticos para a estrutura do conteúdo e no uso das técnicas de CSS Grid Layout e Flexbox para a criação de layouts (sem o auxílio de frameworks) e na inclusão de características de responsividade

## 2. Tema do Trabalho
Desenvolver uma simulação de interface de um site de e-commerce fictício
O design e a escolha exata dos produtos são livres, mas a estrutura das páginas deve seguir os requisitos mínimos detalhados abaixo

## 3. Requisitos Técnicos

### HTML5 Semântico:
A estrutura das páginas deve ser construída com elementos semânticos do HTML5, como <header>, <footer>, <nav>, <main>, <section>, <article>, <aside>, e <figure>
O código HTML deve ser bem estruturado

### CSS3:
A estilização deve ser feita em uma folha de estilo externa (.css)
O layout principal das páginas deve ser construído com CSS Grid Layout
O alinhamento e distribuição de itens dentro de componentes (micro-layout, como cards de produto, itens de menu, etc.) deve empregar Flexbox
Devem ser usadas propriedades CSS para estilizar adequadamente os elementos nas páginas (cores, tamanhos, margens, textos, etc…)

### RESTRIÇÕES: Neste primeiro trabalho não devem ser utilizados:
frameworks CSS como Bootstrap, Tailwind, Foundation, etc
frameworks JavaScript (React, Vue, Angular) ou bibliotecas como jQuery. O foco é exclusivamente em HTML e CSS puros

## 4. Estrutura de Páginas
O projeto deverá conter, no mínimo, 3 páginas como descrito a seguir, interligadas por links de navegação:

* Página Inicial:
  * Deve conter um cabeçalho com o logo/nome da loja (mantido nas outras páginas)
  * Uma área de "Produtos", apresentando uma grade com pelo menos 4 categorias de produtos
  * Informações sobre o site no pé da página (mantido nas outras páginas)
* Página para uma das Categorias de Produtos:
  * Deve listar os produtos de uma categoria (ex: "Smartphones")
  * O layout principal desta página será uma grade com "cards de produto"
  * Cada card de produto deve conter pelo menos uma imagem, nome, preço e um botão/link "Comprar"
* Página de Detalhes de um dos Produto:
  * Apresenta as informações de um único produto
  * O layout deve ser dividido em duas colunas principais:
    * Coluna Esquerda: Imagem do produto
    * Coluna Direita: Nome do produto, descrição, especificações técnicas, preço e um botão "Adicionar ao Carrinho"
 
## 5. Desenvolvimento

Procurem por inspiração em páginas de e-commerces conhecidos!

O trabalho deve ser desenvolvido em duplas!
